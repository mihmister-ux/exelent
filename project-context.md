## 7. НОВЫЕ ПРАВИЛА РАБОТЫ (Обновление 2026-11-16)

- **Модель:** Работаем в режиме гибкого переключения. Основная — DeepSeek V4 Flash ($0.0125), для сложных задач — DeepSeek V4 Pro ($0.025), для критических — GPT-6.1 Sol ($0.10) или Claude Sonnet 5.5 ($0.09). Агент может быть переключён в любой момент. Если задача сложная и Flash не справляется — сам предложи переключиться на Pro.

- **Задача Excel:** Делаем PWA-замену Excel. Фичи: парсинг накладных (Excel/PDF), сканер ЧЗ (DataMatrix), авто-сортировка по срокам, кнопки «Продан» / «Вернуть».
- **Бюджет:** ~$8.50. Работаем экономно, не жечь токены впустую.

## 8. СКРИПТЫ ВМЕСТО ЧТЕНИЯ (Обновление 2026-11-20)

**Правило:** перед любым чтением файла в чат (cat/Read/grep по нескольким файлам) — сначала скрипт, который печатает только сухой отчёт. В контекст попадает отчёт, а не исходник.

- **Поиск по коду** (переменная, строка, функция) — `node scripts/find.mjs '<шаблон>' --files a.ts,b.ts --ctx 1` или короткий `node -e "..."`. Вывод: файл + строка + 1–2 строки контекста. Файл целиком не открывать.
- **Проверка данных** (количество, даты, суммы) — скрипт печатает цифры (`{ всего: 146, просрочено: 12 }`), а не сырой JSON.
- **Замена текста в 1–2 файлах** — скрипт `fs.readFileSync` + `replace` + `writeFileSync`, **перед записью бэкап `.bak`**. В чат: файл, число замен, до/после по одной строке.
- **Файл реально нужен целиком** (новый файл, сложная логика) — сначала спросить Мишу, оправдано ли чтение, и показать размер: `node scripts/find.mjs x --lines --files <файл>`.
- **Проверка после правок:** `npx tsc --noEmit` → exit 0. Для сборки — ровно команда CI (`npm run build`), т.к. `--noEmit` пропускает то, что ловит `tsc -b`.
