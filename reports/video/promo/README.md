# HTML-прототип промо для HyperFrames

## Что в папке
- `index.html` — готовая композиция (показывает «Было (Excel) → Стало (программа)» по раскадровке `pitch-to-customer.md`).
- `assets/*.jpg` — реальные скриншоты приложения (Сроки, Товары, Загрузка, Выгрузка).
- `RENDER.md` — как поставить FFmpeg и отрендерить MP4.

## Как открыть предпросмотр
Просто откройте `index.html` в браузере — анимация работает «как есть» (HTML playable, без build-этапа).

## Как отрендерить MP4
1. Поставить Node ≥ 22 (у вас v24 — уже есть).
2. Установить HyperFrames CLI: `npm i -g hyperframes`
3. Поставить FFmpeg (обязателен для рендера): winget/choco/обязательно `ffmpeg` в PATH.
4. В папке `reports/video/promo/`:
   ```
   npx hyperframes preview   # предпросмотр сライブ-перезагрузкой
   npx hyperframes render    # MP4 в .hyperframes/output
   ```

## Как собран `build/promo.mp4` (рабочий путь)

`node build_video.cjs` — собирает MP4 из 6 ключевых кадров сцен
(`build/scene-s0..s5.png`) + `build/music.wav`: кроссфейды 0.6 с между сценами,
H.264 CRF 20, AAC 160k, 1280×720. Результат — **35 с, 1050 кадров, ~1.6 МБ**.

Почему не покадрово через `render.cjs`: headless Chrome в этой песочнице Windows
не стартует — падает на `FATAL: mojo platform_channel … Отказано в доступе (0x5)`,
потому что создание named pipes запрещено. Проверены `--headless=new/old`,
`--single-process`, `--no-zygote` — все варианты падают одинаково, CDP-порт не
открывается. Поэтому кадры сняты по одному на сцену, а плавность дают кроссфейды.

Чтобы переснять ключевые кадры после правок `index.html`, нужен браузер вне
песочницы (обычный Chrome на машине), затем `node build_video.cjs`.

## Что показывает ролик (≈ 30–40 сек)
1. Старая Excel-таблица (сроки тонули среди строк).
2. Загрузка накладной — разбор строк само.
3. «Сроки» — группы Просрочено / Истекает / В наличии.
4. «Продано» / «Списать» в два касания.
5. «Выгрузить в Excel» + резервная копия.
6. Финал: «Всё под рукой. Проще, чем таблица.»
