# EXELent

**Журнал контроля сроков годности товара — вместо Excel-таблицы.**

EXELent показывает, какой товар просрочен, что истекает в ближайшие 60 дней, а что уже продано. Загружаете накладную или добавляете товар вручную — приложение само раскладывает позиции по срокам и подсказывает, что делать. Выгрузка в Excel остаётся, если нужно распечатать журнал или сдать его в архив.

Никакой регистрации, никакого интернета после установки: все данные хранятся только на вашем устройстве.

---

## Как запустить

Понадобится установленный [Node.js](https://nodejs.org/) (версия 20 или новее).

```bash
npm install
npm run dev
```

Затем откройте в браузере адрес, который появится в окне терминала — обычно <http://127.0.0.1:5173>.

Полезные команды:

| Команда | Что делает |
|---|---|
| `npm run dev` | Запускает приложение для работы |
| `npm run build` | Собирает готовую версию для выкладки на сервер |
| `npm run preview` | Показывает собранную версию локально |
| `npm test` | Прогоняет автотесты |

## Как пользоваться

### 1. Загрузить накладную

Откройте раздел **«Накладная»** и перетащите файл — или нажмите на рамку и выберите его.

Подойдут:

- **Excel** — `.xlsx`, `.xls`, `.xlsm`
- **PDF** — счёт или накладная от поставщика

Приложение само найдёт в файле таблицу товаров и покажет, что прочитало: наименования, количество, сроки годности, поставщика. Проверьте список глазами — если что-то распозналось неверно, это видно сразу, до сохранения. Нажмите «Загрузить» — позиции появятся в журнале.

Если файл не получилось прочитать, вы увидите объяснение, что именно не так, а не пустой экран.

### 2. Добавить товар

Раздел **«Товары»** → кнопка добавления. Заполнить нужно всего четыре поля: наименование, поставщик, годен до и дата поступления (она подставляется сегодняшней — обычно её менять не нужно).

Если у товара есть код маркировки «Честный знак», нажмите иконку сканера и наведите камеру на квадратный код на упаковке — данные подставятся сами.

### 3. Отметить «Продан»

На главном экране **«Сроки»** прокрутите до нужного товара и нажмите кнопку с галочкой — позиция уйдёт в **«Архив»** и пропадёт из списка на полке.

Если нажали по ошибке, в уведомлении внизу есть кнопка **«Отменить»** — товар вернётся на место.

В архиве любую позицию можно вернуть в наличие, а просроченную — списать и распечатать акт.

### 4. Выгрузить в Excel

Раздел **«Товары»** → кнопка **«Выгрузить в Excel»**. Скачается файл `.xlsx` с тем же порядком колонок, что и в вашем привычном журнале: п/н, наименование, дата поступления, годен до, остаток, истёк срок, выбыл, честный знак, дата акта.

Этот файл можно печатать, отправлять руководителю или хранить как архив. Но помните: **главный журнал — в приложении**. Правки, сделанные в скачанном файле, обратно не попадут.

## Чем ещё помогает

- **Сроки по группам** — просрочено, истекает в течение 30 дней, 31–60 дней, остальное, без срока. Красное сверху, спокойное снизу.
- **Недельная сводка** — на главном экране видно, что истекает на этой неделе.
- **Фильтры** — поиск по названию и отбор по поставщику, чтобы не листать весь список.
- **Печать списка** — просроченные можно распечатать одним нажатием.
- **Резервная копия** — в разделе выгрузки есть сохранение копии базы и восстановление из неё.

## Технологии

Приложение сделано на:

- **React** — интерфейс
- **Vite** — сборка и запуск
- **TypeScript** — код без опечаток
- **Dexie** — хранение данных прямо в браузере, на устройстве пользователя

Дополнительно: чтение Excel через SheetJS, распознавание PDF-накладных через pdf.js, сканирование кодов маркировки через ZXing.

Приложение работает как PWA: его можно установить на телефон или компьютер и открывать как обычное приложение, в том числе без интернета.

---

## Важно про данные

Всё хранится локально, в браузере. Поэтому:

- данные не уходят на сервер — их не увидит никто, кроме вас;
- если очистить данные браузера, журнал пропадёт — делайте резервную копию;
- в режиме инкогнито приложение работать не будет.
