## 1. Задача в одном абзаце

Есть Excel-журнал контроля сроков годности товара (`Учёт сроков хранения.xlsm`) с макросами и формулами. Нужно **приложение, где любой человек справится без обучения Excel**: добавить товар и отметить «продано». Excel остаётся для печати/архива, но источником истины становится приложение.

Решение принято: **делаем отдельное приложение**, а не «лечим таблицу». Починка Excel — только как подготовка данных к импорту.

## 3. Что делает автоматика (и почему она ломается)

### Формулы

`F4:F1003` = `=IF(D4="","",IF(D4<TODAY(),"Просрочен",""))`

**Дефект №1 (главный).** На 6 из 7 листов формулы стоят **ниже** данных: на `ЛБренд` с 25-й строки, на `ГРИНФИТО` с 10-й, на `Две Линии` с 36-й, на `Пенталисе` с 33-й, на `Алфите` с 32-й, на `Лотосе` с 25-й. ### Условное форматирование (это работает)

Диапазон `A4:I1003`, три правила (приоритет 1 → 3, побеждает верхнее):

| # | Формула | Заливка | Шрифт |
|---|---|---|---|
| 1 | `AND($D4<>"",$D4<TODAY())` | `#8B0000` тёмно-красный | белый |
| 2 | `AND($D4<>"",$D4>=TODAY(),$D4<=TODAY()+30)` | `#FF0000` красный | белый |
| 3 | `AND($D4<>"",$D4>TODAY()+30,$D4<=TODAY()+60)` | `#FFEB9C` жёлтый | чёрный |

**Смысл цветов сохранить в приложении** — люди к нему привыкли.

### VBA (что удалось прочитать)

Полной декомпиляции не было (исходник в сжатом OLE-потоке), но текстовые фрагменты читаются. Модули: `Module1`, `Module2`, `UserForm1`, `ThisWorkbook`. Подпрограммы и события:

## 4. Полный список дефектов источника

1. **F не работает на 6 из 7 листов** — формулы ниже данных (см. выше).
2. **`Алфит!D25 = '18.09..29'`** — текст вместо даты (видимо 18.09.2029). Выпадает и из формул, и из подсветки, ошибок не выдаёт.
3. **`Две Линии`, строки 24–34 объединены `B:V`** (12 строк): строка 24 без номера в A, нумерация прыгает 20→22, объединения ломают сортировку/фильтр/протяжку. Плюс 13 строк без срока.
4. **`Пенталис`: условное форматирование разъехалось** — диапазоны `A4:I31` + `A32:B32` + `A33:I1003`; на блоке `A33:I1003` формула осталась `$D4`, а при якоре в A33 она смотрит на 29 строк выше (подсветка по чужой дате). У строки 32 отдельные правила ссылаются на `$E32` вместо `$D32`.
5. **Колонки E и I пусты во всех 146 строках** — мёртвые поля шаблона.
6. **«Дата поступления» отсутствует в 4 листах** (0/32, 0/21, 0/28, 9/21).
7. **Проверок ввода (data validation) нет ни в одной колонке** — поэтому и возможны пункты 2 и 3.

## 6. Что строим

**Принцип: два действия вместо девяти колонок.**

### Экраны

1. **«Сроки»** — главный, открывается первым. Группы по опасности: `Просрочено` → `Истекает ≤30 дней` → `31–60 дней` → `Всё остальное` → **`Без срока`** (обязательно отдельной группой, иначе 43 строки потеряются). Сортировка внутри группы — по дате.
2. **«Товары»** — поиск по названию, фильтр по поставщику (7 + «новый»), список всех позиций.
3. **«Добавить товар»** — 4 поля: название, поставщик (выбор из списка), «годен до» (календарь), галочка «Честный знак». «Дата поступления» — сегодня по умолчанию.
4. **«Выгрузить в Excel»** — журнал в текущем виде (те же 9 колонок, листы по поставщикам) для печати и архива.

### Действия

- **«Продано»** — кнопка в строке: ставит `status='sold'` + дату. Ручного ввода в колонку больше нет.

### Модель данных (предложение)

```ts
type ShelfItem = {
  id: string;
  name: string;
  supplier: string;          // 7 известных + любые новые
  receivedAt?: string;       // ISO date
  expiresAt?: string;        // ISO date — ключевое поле
  marked: boolean;           // «Честный знак»
  status: 'in_stock' | 'sold' | 'written_off';
  soldAt?: string;
  note?: string;
};
```

**Правило, которое нельзя нарушать: срок-статус не хранится, а вычисляется из `expiresAt` при показе.** Именно хранение статуса — причина, по которой в Excel колонка F «уехала» и врёт.

Вычисление: `expired` (< сегодня) / `soon` (≤30) / `warning` (31–60) / `ok` / `no_date`.
